# Legacy Canvas 功能清单

来源：`App.tsx` 的命令、快捷键、上下文菜单和属性面板，`CanvasBoard.tsx` 的交互入口，以及 Scene/工程结构。此清单是迁移验收输入，不代表允许复用旧实现。

## 导航

- 左键空白/Alt 手势平移、窗口拖动协作。
- 鼠标位置锚定滚轮缩放，缩放范围 `MIN_ZOOM..MAX_ZOOM`。
- Ctrl+0 重置视图、Ctrl+O 适应全部、Space 聚焦选中、方向键切换聚焦图片。
- 保存并恢复 Scene viewport；Resize、DPR 和多后端恢复。

## 图片

- 文件对话框导入、文件拖放、URL 拖放、剪贴板粘贴。
- 自动排列、打包、移动、缩放、旋转、多对象变换。
- 删除、复制、剪切、粘贴、重复、前后层级。
- 锁定、隐藏、透明度、灰度、水平/垂直翻转。
- 非破坏裁切、恢复完整图片、重置变换、原比例。
- 图片评论、标签、源文件定位、导出、取色。

## 选择与命中

- 单选、Shift 增减、多选、Ctrl+A、Escape 清空。
- 空白框选、拖出视口自动平移、重叠对象按 zIndex 命中。
- 8 方向控制点、四角独立旋转柄、多对象 bounds 变换。
- WebGL 图片平面与 Konva 命中代理同步。

## 分组

- 创建/解散、嵌套成员、移动组及后代。
- 调整组框、背景颜色/透明度、标题颜色、重命名。
- 折叠、隐藏成员、锁定组框尺寸、删除。
- 普通标题和紧凑标题两种显示方式。

## 标注

- Q 进入/退出；1/2/3/4 选择画笔、箭头、矩形、椭圆；E 橡皮。
- 颜色、线宽、选择、移动、锁定、隐藏、删除。
- 标注可成为分组成员。

## 排列与吸附

- 左/右/上/下对齐。
- 统一宽、高、尺寸。
- Pack、Pack and Fit。
- Scene `canvas.snap` 和 padding 设置。

## 工程与外壳协作

- 新建、保存、另存为、打开、导入工程、最近打开。
- Undo/Redo、dirty revision、关闭提示、Scene version 2。
- Asset 引用、缓存重开、缺失资源错误、viewport 恢复、zIndex 恢复。
- 属性面板、Outline 搜索/折叠、上下文菜单、快捷键。
- 窗口置顶、点击穿透、位置锁定、透明度、最大化/最小化。
- F10 性能面板、诊断日志、benchmark/smoke 接口。

## 仓库中未发现的独立功能

- 没有独立文本节点；只有分组标题和图片评论文本。
- 没有独立参考线系统。
- 没有独立可配置网格渲染；仅存在吸附开关。
- 没有视频节点的实际渲染实现，类型中仅保留 group member `video` 值。
