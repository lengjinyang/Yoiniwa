# Pose Studio 操作逻辑与实现

本实现采用 clean-room 方式复现通用的 3D 摆姿工作流：只依据公开用户文档理解“用户能做什么”，没有复制 Magic Poser 的代码、模型、图标、品牌、付费素材或私有数据格式。最终界面继续使用宵庭自己的视觉语言和 CC BY 4.0 BJD 资产。

## 操作模型

- 拖动：用于大范围改变。手腕和脚踝走两段 IK；肘和膝改变 pole；胸、头和骨盆带动上游身体。
- 旋转：用于局部微调。球关节使用屏幕空间 swing/twist，肘膝和指节按 rig 限位只做铰链屈伸。
- 选择：点击控制点或身体分件进入对应分支；点击空白收起；双击把相机旋转中心移到当前关节。
- 相机：右键旋转、中键平移、滚轮缩放；视角方块和右栏提供正、背、左、右、顶、底六个标准视角。
- 手指：选择手腕进入共享 WebGL 上下文的第二个 scissor 视口；可选单指、整指弯曲、拖动指尖或逐节旋转。
- 预设：点击预设后可在 0%–100% 之间混合；位置做线性插值，旋转做最短路径 quaternion slerp。
- 镜像：把当前一侧的手臂或腿镜像到另一侧；交换左右会同时镜像并互换两侧姿势。
- 固定：固定手掌或脚掌后，移动骨盆/躯干会迭代重解四肢，尽量保持世界坐标不变；不可达时显示限位提示。
- 历史：一次拖动、滑杆拖拽、镜像、视角切换或重置形成一条撤销记录。
- 预览/导出：预览和 PNG 渲染隐藏所有控制点、圆环、辅助线与手部编辑视口。

## 实现分层

1. `PoseStudio.tsx` 负责编辑器壳层、预设/手指/相机面板、上下文动作和撤销栈。
2. `PoseRuntime.ts` 负责 Three.js 场景、射线命中、统一指针状态机、IK/FK、相机、灯光和 PNG 输出。
3. `twoBoneIk.ts` 提供解析式两段 IK；`PoseRuntime` 再把解分配到 BJD 双关节并应用 rig 限位。
4. `posePresets.ts` 负责预设校验、应用和强度混合。
5. `poseOperations.ts` 负责关节/肢体重置以及左右镜像、交换。
6. `PoseDocumentV1` 是持久化边界；最终姿势只保存根变换、局部关节 quaternion、IK pole/固定状态、相机、灯光和外观。

## 指针状态机

`pointerdown` 先按屏幕像素命中半径选择控制器，再回退到射线命中身体分件。开始拖动时冻结相机、保存文档快照，并创建穿过控制点且面向当前相机的交互平面。`pointermove` 将鼠标投影到该平面，按目标类型分发到 IK、pole、指尖 CCD 或关节旋转。`pointerup` 恢复相机并提交一条历史记录。

这种平面拖动保留了二维输入的直接感；想改变前后深度时，先换到侧视或使用视角方块，再继续拖动即可。

## 当前产品边界

宵庭的 Pose Studio 是“生成一个可反复编辑的姿势参考节点”，不是云端 3D 社区或素材商城。因此没有复刻账号、订阅、社区、云备份、专有角色库和 OBJ 导出；多角色/道具编排仍由宵庭画布承担。核心摆姿、相机、灯光、外观、预设、手指、镜像、撤销和导出流程均在本地完成。
