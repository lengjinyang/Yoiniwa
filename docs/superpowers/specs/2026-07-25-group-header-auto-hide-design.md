# 分组标题栏自动隐藏设计

日期：2026-07-25

## 目标

画布内分组标题栏只在鼠标位于该组的可见范围内时显示；鼠标离开后延迟 140 ms 隐藏，以避免边界闪烁。此行为与选中状态无关。

## 范围

- 普通展开组：使用完整组框范围判断。
- 折叠组：使用 `groupVisibleBounds()` 返回的折叠胶囊范围判断。
- 低缩放 compact header：与常规标题栏共享可见状态。
- 嵌套组：按现有渲染顺序命中最上层可见组。
- 不改变组背景、边框、Transformer、成员可见性、选中逻辑和 App 层浮动编辑菜单。

## 方案

在 `CanvasBoard` 内维护单个 `hoveredGroupId` 和一个隐藏计时器。Stage 的鼠标移动事件无论当前是否存在手势，都先把屏幕坐标转换为世界坐标，再查询已有 `groupIndex`，过滤未渲染或被父组隐藏的组，并选择渲染顺序中最上层且包含指针的组。

命中组时立即显示其标题栏并取消隐藏计时；离开所有组时启动 140 ms 计时，届时清除当前组。Stage 离开窗口时使用同一延迟隐藏逻辑。

`GroupFrame` 和 `GroupCompactHeader` 接收 `headerVisible`：

- `GroupFrame` 始终保留边框与可交互框架，只切换内部标题栏 Konva Group 的 `visible`。
- `GroupCompactHeader` 在低缩放条件满足且 `headerVisible` 时渲染。
- 标题隐藏后不会拦截 pointer events；组边框仍可选择。

## 边界行为

- 组拖动期间维持当前标题可见，避免拖动句柄消失。
- 组重叠时仅显示视觉上最上层的组标题，避免多个标题同时弹出。
- 鼠标从一个组直接移入另一个组时立即切换，不等待隐藏延迟。
- 触摸移动不驱动 hover；触摸现有选择和拖动行为不变。
- 场景变化使当前 hover 组消失或隐藏时，清除该状态。

## 验证

- 为纯命中选择逻辑增加单元测试：组内、组外、折叠组、重叠组和隐藏组。
- 运行 `npm test -- --run`。
- 运行 `npm run build`。
- 运行 `npm run smoke:dev`，补充桌面断言验证组内显示、组外隐藏。
- 最后运行 `npm run dev:test` 并保持窗口打开。

## 非目标

- 不增加用户设置或场景字段。
- 不修改 `.refcanvas` 格式。
- 不重构 Konva Layer。
- 不改变选中组上方浮动编辑菜单的现有自动隐藏逻辑。
